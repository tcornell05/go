# Game Controls

## Movement
- **WASD** / **Arrow Keys**: Move player
- **Q, E, Z, X**: Diagonal movement
- **Backtick (`)**: Toggle between grid and smooth movement

## Interface
- **Tab** / **B** / **Space**: Toggle inventory drawer/catalog (multiple keys for reliability)
- **M**: Toggle inspect mode (shows magnifying glass cursor and lime border)
- **I**: Inspect object at cursor (when hovering over furniture)
- **Middle-click**: Direct inspect (alternative to I key)

## Editor Mode (when enabled)
- **P**: Toggle position dialog
- **F2**: Toggle debug grid
- **Escape**: Close dialogs

## Inspection Mode
When inspection mode is active (press M):
- **Lime green border** appears around screen
- **Magnifying glass cursor** replaces normal cursor
- **I key** or **middle-click** on furniture to open inspection dialog

## Troubleshooting
If inventory doesn't show:
- Try **Tab**, **B**, or **Space** keys
- Look for inventory toolbar button on right side of screen
- Should show: Floors, Walls, Furniture, Decorations categories

If inspect mode doesn't work:
- Try **M key** to toggle inspect mode
- Look for lime green border around entire screen
- Cursor should change to magnifying glass when active
- Try clicking furniture with **I key** or **middle-click**
